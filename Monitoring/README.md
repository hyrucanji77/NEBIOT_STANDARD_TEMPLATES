# NEBIOT Monitoring Report templates 1.3

Complete American English and Spanish Monitoring Report templates, aligned with NEBIOT Standard 0.8.2 and the PD, Ex-Ante, Ex-Post and Environmental Accounts edition 1.2.

`Word/` contains DOCX reports; `Word_Templates/` contains reusable DOTX masters; `Overleaf/` contains the full LaTeX project and original logos; `PDF/` contains compiled reading previews. `Guides/` explains completion and evidence handling. `Registers/` maps the monitoring sections to the source templates and calculation notation.

Select one controlled writing format. The report summarizes the same quantitative account as its attached or embedded Ex-Post report; it does not create an additional result. Existing source templates, accounting workbooks and the governing standard are not modified by this package.

In Overleaf, use XeLaTeX and the English or Spanish root named `NEBIOT_Monitoring_Report_EN.tex` or `NEBIOT_Monitoring_Report_ES.tex`.
